# Kridiya Marketing System

This folder turns Kridiya's strategy into an operating system.

## Start here

1. Read `../KRIDIYA_DIGITAL_MARKETING_AND_GROWTH_SYSTEM_PLAN.md`.
2. Use `SKILL_COVERAGE_MATRIX.md` to understand which marketing capabilities apply now, later, or not yet.
3. Launch the first controlled campaign using `STARTER_CAMPAIGN_AND_AD_KIT.md`.
4. Run publishing from `90_DAY_CONTENT_CALENDAR.csv`.
5. Review performance in `CAMPAIGN_SCORECARD.csv`.
6. Prioritize improvements in `EXPERIMENT_BACKLOG.csv`.

## Operating rhythm

### Daily

- Assign new enquiries.
- Check first-response time.
- Complete due follow-ups.
- Confirm campaign tracking is present.
- Record quote, payment, booking, and lost outcomes.

### Weekly

- Review spend, qualified leads, quotes, bookings, and gross profit.
- Review search terms, creatives, landing pages, and lost reasons.
- Approve the next content week.
- Select no more than three improvement experiments.

### Monthly

- Reconcile advertising reports with Supabase bookings and finance.
- Reallocate budget using gross-profit contribution.
- Review repeat/referral performance.
- Audit permissions, consent, opt-outs, claims, and expired offers.
- Prepare the next seasonal campaign.

## Decision rule

Do not scale marketing faster than Kridiya can respond, quote, fulfil, and measure.
