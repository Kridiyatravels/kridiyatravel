# Kridiya Microsoft 365 Folder Guide

Main operating system: Supabase/admin site.
Microsoft 365 role: file storage, Excel review, backup, and accountant handover.

## Daily Use

- Save booking-related files in `Bookings`.
- Save payment proofs and payment-link screenshots in `Payments`.
- Save generated invoices, payment requests, receipts, and supplier invoices in `Accounting`.
- Save corporate client documents in `Corporate Clients`.
- Save B2B supplier portal screenshots, invoices, and references in `Supplier Portals`.
- Save trade license, bank, Stripe, Tabby/Tamara, PayPal, and company setup documents in `Company Documents`.
- Save exported CSV backups from the admin `Backups` page in `Monthly Backups/YYYY-MM`.
- Save email/WhatsApp templates and staff training steps in `Templates & SOPs`.

## Monthly Backup Routine

1. Open admin staff site.
2. Go to `Backups`.
3. Click `Download all`.
4. Upload all CSV files to `Monthly Backups/YYYY-MM`.
5. Open `Accounting`.
6. Click `Export report`.
7. Upload the accounting CSV to `Accounting/Monthly Reports`.

## Accounting Routine

- Use the admin `Accounting` page as the live view.
- Use Excel CSV exports for accountant review and bank reconciliation.
- Keep supplier invoices in `Accounting/Supplier Invoices`.
- Keep customer invoices and receipts in `Accounting/Invoices & Receipts`.

## Security Rule

Only the owner/admin should access this folder until staff roles and folder permissions are planned.
Do not store passwords in Excel, Word, or plain text files.
