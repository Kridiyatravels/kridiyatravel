# Production Prompt Set

## Shared hero prompt

Use case: stylized-concept. Asset type: 1600×700 website hero for Kridiya
Travel and Tours, UAE. Create a fully original premium monoline editorial
explainer illustration with refined thin charcoal-grey strokes of consistent
weight, mostly white interiors, sparse saffron orange, golden yellow,
warm-cream, and deep-brown flat fills, with very small muted blue or green
accents only when useful. Use clean geometric travel objects, minimal
simplified people, a calm professional composition, and generous open margins.
No text, letters, numbers, logos, watermarks, black borders, heavy shadows,
blur, gradients, 3D, cartoon mascots, glossy icon-pack styling, random floating
stickers, dark backgrounds, stock-photo realism, or black bars.

Generate on a perfectly uniform flat `#00ff00` chroma-key backdrop with no
shadow, gradient, texture, floor plane, reflection, glow, or lighting
variation. Never use `#00ff00` inside the subject.

## Mini spot prompt

Create one centered 512×512 transparent vector spot object in the same Kridiya
monoline system. Use a `#5B554F` rounded stroke, mostly white or `#FFF6E7`
interiors, and small `#F4A62A`, `#F6C85F`, or `#4A3B31` accents. Use muted blue
or green only where semantically useful. Keep a generous clear margin and a
simple recognizable silhouette. No text, logo, watermark, gradient, shadow,
3D, or background panel.
