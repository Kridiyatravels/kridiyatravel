# kridiyatravel

Static website for Kridiya Travel and Tourism FC-LLC.

## Files

- `index.html` is the home page.
- `about.html`, `flights.html`, `hotels.html`, `holidays.html`, `visa.html`, `contact.html`, `login.html`, `register.html`, `account.html`, and `thanks.html` are site pages.
- `css/`, `js/`, and `assets/` contain the site styling, behavior, and images.

## GitHub Pages

Upload these files to the `kridiyatravel` repository. Keep `index.html` at the top level so GitHub Pages can load the site homepage.
